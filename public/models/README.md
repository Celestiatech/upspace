# Floorverse 3D Models Directory
Place `.glb` or `.gltf` 3D building models here.

Examples:
- `business-tower.glb`
- `restaurant-tower.glb`
- `hotel-tower.glb`
- `shopping-mall.glb`
- `gaming-tower.glb`
- `creator-tower.glb`
- `auto-tower.glb`
- `technology-tower.glb`

If no GLB file is present, the 3D viewer automatically falls back to rendering a high-detail procedural building tailored to the active arena theme.
